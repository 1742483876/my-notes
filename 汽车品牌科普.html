🔑 核心记忆法
奔驰：字母越靠后越高端 → A < C < E < S（S=Super）
宝马：数字越大越高端 → 1 < 3 < 5 < 7（奇数=轿车，偶数=轿跑）
奥迪：A+数字越大越高端 → A3 < A4 < A6 < A8（Q=SUV，S/RS=性能）
对应关系：C级 = 3系 = A4 | E级 = 5系 = A6 | S级 = 7系 = A8
SUV：GLC = X3 = Q5 | GLE = X5 = Q7
